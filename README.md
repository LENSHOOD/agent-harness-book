# Agent Harness：从执行脚手架到自我进化系统

一本面向企业 Agent 平台架构师和高级工程师的中文开源阅读站点。

## 在线阅读

https://lenshood.github.io/agent-harness-book/

## 本地运行

```bash
npm install
npm run docs:dev
```

## 构建

```bash
npm run docs:build
```

正文位于 `docs/chapters/`，站点由 VitePress 生成，通过 GitHub Actions 部署到 GitHub Pages。
